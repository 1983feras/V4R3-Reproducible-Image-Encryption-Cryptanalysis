# Research Ethics and Security Scope

All cryptanalytic experiments in this repository target the authors' own experimental constructions or deliberately weak positive controls. The work is intended for defensive academic evaluation and reproducibility. It does not target third-party deployed systems, credentials, services, or user data.

The study follows Kerckhoffs' principle by publishing algorithmic details and public test vectors while keeping the security claim empirical and bounded. Production use is not recommended; standardized, extensively analyzed authenticated-encryption schemes remain the appropriate baseline for deployed confidentiality and integrity.
